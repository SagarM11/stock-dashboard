🆕 IPO Monitor

GMP = unofficial grey-market premium (speculative, updates through the day). The listing-gain range blends GMP% with subscription demand — a scenario, not a forecast. Weak subscription = GMP often doesn't hold. Not investment advice.
IPO Monitor needs a (free) IPO Guru API key
1. Register free at ipoguru.in → get your API key
2. Add IPOGURU_API_KEY=your_key to api_credentials.txt
3. Run python3 ipo_monitor.py (or wait for the scheduled routine)
